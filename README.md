Projects are organized by language or technology and range from simple exercises to complete small applications.

## 📂 Repository Structure

```text
dev_sandbox/
├── python/

└── ...
```

Each directory contains projects related to a specific language or technology.

* **Python** — Automation, games, GUI applications, utilities, and other projects.
* **Web** — Frontend experiments and web applications.
* **More to come** — Additional languages and technologies will be added as they become part of my development work.

This repository is primarily for experimentation, practice, and smaller projects that don't warrant a dedicated repository.
